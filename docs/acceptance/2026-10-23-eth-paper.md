## Market observation

The bounded observation sampled roughly every five seconds for 30 minutes. It included order operations, the deliberate network interruption, layout changes and history browsing; it is not an uninterrupted four-pane latency benchmark. Sampling reports packet age relative to backend `server_time`, not exchange-to-screen tick latency. Existing documented trade-volume limitations remain; no volume acceptance is claimed.

The sampler completed 360 snapshots (29.93 minutes between first and last sample). Each interval recorded 204 distinct last prices. Across sampled last bars, zero OHLC ordering violations were found. Packet-age p95 was 1.40–1.42 seconds; maximum was 2.49 seconds. These five-second samples cannot prove every tick was delivered or measure intratick latency. Brief pane removal during layout checks explains the slightly smaller companion sample counts (359/359/358).

Queue saturation remains a documented stability limitation, not a fixed issue or a reason to increase queue capacity without a separate measured comparison.

The current process log review found no `KeyError`, traceback, or failed IB job. It also recorded no inactive-contract callback warnings, so it does not prove that the newly guarded late-callback case occurred live. PR #55's offline boundary tests remain the evidence for that case.
